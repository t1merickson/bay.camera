# bay.camera

A full-screen, interactive map of live public webcams and weather across the
San Francisco Bay Area — built for watching **fog, marine layer, and light**
(originally for photographers, useful to anyone). A revival of Tim's ~2019
static webcam directory.

> Picking this up? Read [RESUME.md](RESUME.md) first — it has current state,
> open threads, and gotchas.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321/
npm run build      # static site → dist/
npm run preview    # serve the built dist/
```

Data regeneration:

```bash
npm run fetch:alertca   # refresh data/alertcalifornia-bay.json from the ALERTCalifornia API
```

## Stack

- **[Astro](https://astro.build)**, static output — every page renders to
  plain HTML at build time. No server, no SSR.
- **[MapLibre GL JS](https://maplibre.org)** — the interactive map (the app's
  one heavy dependency, ~221KB gz). Basemap tiles from **Carto** (free, no
  key). Cloud overlay from **RainViewer** (free, no key).
- **Hand-rolled CSS** — a small shadcn-style design system (HSL tokens,
  light/dark, subtle borders). **No Tailwind, no React, no UI library.** The
  entire app is one page + one inline script.

Everything is a **single static bundle** deployable to any static host
(Netlify is the assumed target). No API keys anywhere.

## How it works

The whole app is **`src/pages/index.astro`** — markup for the HUD/panels plus
one inline `<script>` that drives MapLibre and all interactions:

- A full-viewport MapLibre map (Carto dark/light basemap by `prefers-color-scheme`).
- Camera markers from a GeoJSON source with **clustering** (nearby cams collapse
  into a count bubble; expand on zoom), colored by region.
- Click a marker (or a browse-list item) → the right **preview panel** opens
  with the live still (or play-on-demand video, or a link), region, attribution,
  source + donation links. Cameras are shareable via `#cam/<id>` deep links.
- Top **HUD**: brand, live NWS coast-vs-bay fog readout (KHAF/KSFO), a **Clouds**
  overlay toggle, and a **Live** toggle (default is a single still per camera;
  Live auto-refreshes the open preview, pausing on hidden tab, 12h politeness cap).
- Left **browse panel** (the "Cameras" button): the full list, grouped by region,
  with region filter chips.

### Data model

`data/cameras.json` is the **single source of truth** — one record per camera
(location, coords, vendor `type`, embed, attribution, sources, donation,
`status`, resiliency `flags`). The app renders every non-`dead` camera; cams
with coordinates get a map pin. Full schema + vetting rules in
[docs/data-model.md](docs/data-model.md); vendor types + resiliency notes in
[docs/vendors.md](docs/vendors.md).

`data/alertcalifornia-bay.json` — 183 Bay Area peak cameras from the
ALERTCalifornia wildfire network (generated by `scripts/fetch-alertcalifornia.py`).
Staged for a future toggleable "peak cams" map layer; **not wired in yet**.

## Data sources (all free, no key)

- **NWS** `api.weather.gov` (MTR office) — current conditions / fog readout.
- **Carto** basemaps — map tiles (© OpenStreetMap © CARTO).
- **RainViewer** — satellite cloud overlay.
- **GOES-18** (NOAA STAR, `psw` sector) — satellite imagery cameras.
- **ALERTCalifornia**, **Caltrans D4**, **USGS CoastCam**, **NPS**, **NDBC**,
  and many broadcast/community feeds — see [docs/vendors.md](docs/vendors.md).

## Verifying UI changes

`claude-in-chrome` and Codex's browser were unpaired during development, so UI
checks were headless-Chrome screenshots. **MapLibre needs WebGL**, which
headless only has via SwiftShader — and even then it renders the raster basemap
but **not** the vector marker layers, so confirm markers in a real browser.
Headless screenshot recipe:

```bash
CHROME="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"
"$CHROME" --headless=new --enable-unsafe-swiftshader --use-gl=angle \
  --use-angle=swiftshader --hide-scrollbars --window-size=1440,900 \
  --virtual-time-budget=10000 --run-all-compositor-stages-before-draw \
  --screenshot=/tmp/shot.png "http://localhost:8090/"
```

## Attribution / ethos

Only **free, public** webcams — no paywalls, no logins. Where a source requests
donations, that ask is carried forward in the camera's card (`donation` field).
